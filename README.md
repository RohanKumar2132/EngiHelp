Project Overview

EngiHelp is a web application that aims to support engineering students with valuable resources, course roadmaps, frequently asked questions (FAQs), and the ability to check and download their RGPV exam results.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Features

Navbar: Sticky navigation bar that helps users quickly access different sections of the website.

Hero Section: A welcoming section with an image carousel and brief introduction.

Resources: A collection of helpful resources displayed in a single row with horizontal scrolling.

Roadmaps: Various engineering course roadmaps to guide students in their academic journey.

FAQs: Commonly asked questions with answers to help students get quick information.

RGPV Result Checker: An integrated feature to check and download RGPV results using scraping techniques.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Technologies Used

Frontend: HTML, CSS, JavaScript (Vanilla JS)

Backend: Python,Javascript

Web Scraping: BeautifulSoup and Requests (Python) for RGPV result scraping

Design: Flexbox, CSS Grid for layout, and modern UI design practices

Contact Form: A contact form for users to get in touch with the website owners.
